Timetable Lite guide

  1. Schedule: save your institute and working days, then build periods or add periods and breaks manually.
  2. Classes: add each class or batch and optional section.
  3. Subjects: add subjects; marking a subject core asks the generator to try to separate demanding lessons.
  4. Teachers: choose subjects, available days and optional period restrictions.
  5. Allocation: choose class, subject and teacher, weekly lessons, daily maximum and double-period rules.
  6. Generate: review class, teacher or master views. In Class view select a lesson and its destination to move or swap. Download PDF/images or print.

What stays in this browser?

After you use Add, Save or Build, the app saves institute name, year and logo, working days, periods and breaks, classes and sections, subjects, teachers and availability, allocations and holidays. Generated lessons and successful moves, swaps and undo are saved too. There is one current setup per browser profile and site address, with no automatic expiry set by this app.

Unsubmitted form entries, the current screen/view, calendar-week selection and undo history are not restored after reload. Changes to institute/day settings, periods, classes, subjects, teachers or allocations clear generated lessons; your setup remains and you must generate again. Rebuilding periods also clears teacher period restrictions. Deleting a class, subject or teacher removes linked allocations.

Use the same browser profile and site address to return to your work. Other devices, browsers and private windows do not share it. Anyone using this profile can access it. Clearing site data, browser cleanup or closing a private session can remove it. There is no account sync or server backup.

Back up and recover

Export backup downloads the complete current setup and timetable as JSON. PDF and images cannot restore your setup. Import backup validates JSON before asking to replace the current setup; export your current work first. A corrupt stored copy is left untouched and saving pauses until you import a valid backup. If storage is unavailable or full, export a backup before closing the tab. Use one editing tab at a time: separate tabs do not merge changes and the last save replaces the stored setup.

Try the sample

Download sample document provides fictional Sample Academy data: two classes, two subjects, two teachers, five working days, a break and 20 generated lessons. Downloading does not change your work. Export your own backup first, then use Import backup to open the sample JSON.

Generation help

If generation fails, check weekly totals, teacher availability, daily limits and double-period rules. A search-limit result does not prove the setup is impossible. Holidays annotate the selected calendar week; they do not cancel or reschedule recurring lessons.
