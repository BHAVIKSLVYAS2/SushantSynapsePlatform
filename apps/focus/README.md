# Focus

Public `/focus` provides a 25-minute timer with pause/resume/reset and browser-saved daily task lists. No sign-in is needed. Tasks include priorities, time estimates, completion, editing, deletion and carry-forward; India dates default to today. Tasks persist in localStorage under `synapse-focus-plan-v1`, shared by tabs in the same browser profile, without task API calls or cross-device sync. Limits: 100 tasks/day, 500/browser and 160 characters/task. Storage failures retain existing tasks and display an error. Clearing browser data removes tasks. Timer state resets on refresh. Previously saved account plans remain preserved in the database through the legacy authenticated API; the new UI does not read, migrate or write those plans.
