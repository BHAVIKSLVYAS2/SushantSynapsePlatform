# Moment Studio

One public creative app combines appreciation certificates and Celebration Studio cards. /moment-studio is the card editor, /moment-studio/certificates is the certificate editor, and ?occasion=condolence (or remembrance) opens a restrained preset. Both editors share section navigation, platform branding, privacy and themes. Certificates retain all eight templates, 17 types/awards, donation amount wording, signatures, organisation logos and explicitly saved browser organisations under the existing storage key. A4 PDF, 300/600 DPI PNG and print remain supported. Cards retain photos, four existing designs and both sizes, adding a quiet botanical design, slate/ivory palette, congratulations, condolences and remembrance. Editable condolence templates support English/Hindi, three tones, three contexts and three wording variants. No AI service, religion, gender or cause of death is inferred. Copy message includes platform credit.

All preview/output renderers stamp the official same-origin platform logo and Sushant Synapse name using branding.mjs. Downloads, generation, file sharing and certificate printing are blocked when the brand logo cannot load. No normal UI removes branding. This browser implementation is not tamper-proof DRM: a real paid watermark-free tier later requires authenticated entitlements and trusted server export generation. No paid tier, checkout, pricing, payment provider or watermark-removal endpoint exists.

Legacy /certificates and /celebration-studio pages/assets are compatibility aliases to the new app. Original source packages are retained for history; allowlisted public aliases use Moment Studio implementation. Legacy favourites/recent IDs are projected to the merged catalogue without rewriting SQLite data; old launch IDs remain accepted by the Node composition. The existing organisation storage key/data remains preserved. Personal card/certificate data stays in the tab; no new persistence, API, schema, upload or backend dependency.

The portal frontend also merges old catalogue entries when talking to the previously deployed Node release. It retains a valid legacy launch/favourite ID for that backend while displaying and navigating to Moment Studio. New Node releases use the canonical moment-studio ID. This adapter avoids restarting the live database-backed server solely for catalogue metadata.
