    About this prototype & review

    Layout proposal only; the deployed app is unchanged. Six selections use existing library text and original editorial meanings. Shri Rudram uses the existing 22-anuvaka unaccented study edition, with chapter summaries rather than full translations. Three recordings reuse the library's licensed assets; other entries explicitly have no verified recording.

    • Compact search and length controls; secondary deity filter opens on request.
    • Contents retain filters, scroll, and selected entry on return. Mobile Back returns to Contents before leaving the prototype.
    • Recite keeps explanation hidden; Learn reveals reading aids, meaning type and source notes.
    • Chapter navigation stays inside a reading, before practice. Outer book navigation stays in its own footer.
    • A cancellable 260ms directional turn follows explicit chapter/reading movement, with no automatic advance. Reduced motion cancels and disables it.
    • Audio stops when leaving a reading or returning to Contents. Repeats never change the selected text or practice counts.

    This is a Codex proposal; Gemini has not reviewed it. Source and licensing metadata come from the app's existing library. The prototype is English-only; production language integration remains separate work.
